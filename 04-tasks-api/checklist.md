# Чек-лист · Таскер API

REST API задач: авторизация по токену, CRUD, фильтры, пагинация, разграничение доступа.

## Авторизация

- [ ] POST /auth/login с верными логином и паролем возвращает 200 и токен
- [ ] Неверный пароль возвращает 401, токен не выдаётся
- [ ] Несуществующий пользователь возвращает 401 без подсказки, что именно неверно
- [ ] Пустые логин или пароль возвращают 400 с указанием поля
- [ ] Другие методы на /auth/login возвращают 405
- [ ] Запрос без заголовка Authorization возвращает 401
- [ ] Запрос с испорченным токеном возвращает 401
- [ ] Токен без префикса Bearer не принимается

## Список задач

- [ ] GET /tasks возвращает 200 и список задач текущего пользователя
- [ ] В ответе есть поля пагинации: номер страницы, размер, общее количество
- [ ] limit ограничивает число элементов на странице
- [ ] page переключает страницы, элементы не повторяются и не теряются
- [ ] Последняя страница может быть неполной
- [ ] Страница за пределами диапазона возвращает пустой список, а не ошибку
- [ ] Нечисловые page и limit отклоняются с 400
- [ ] Отрицательные и нулевые page и limit отклоняются
- [ ] Слишком большой limit либо ограничивается потолком, либо отклоняется
- [ ] Фильтр по статусу возвращает только задачи этого статуса
- [ ] Неизвестное значение фильтра обрабатывается предсказуемо

## Задача по id

- [ ] GET /tasks/{id} существующей своей задачи возвращает 200 и объект
- [ ] Структура объекта совпадает с элементом списка
- [ ] Несуществующий id возвращает 404
- [ ] Чужая задача возвращает 404, а не 200 и не 403 с утечкой данных
- [ ] Нечисловой id возвращает 400 или 404, но не 500

## Создание задачи

- [ ] POST /tasks с корректным телом возвращает 201 и созданный объект
- [ ] В ответе есть присвоенный id
- [ ] Созданная задача появляется в списке
- [ ] Пустой обязательный заголовок отклоняется с 400 и указанием поля
- [ ] Отсутствующее обязательное поле отклоняется с 400
- [ ] Неизвестный статус отклоняется с 400
- [ ] Поле не того типа отклоняется с 400
- [ ] Избыточно длинный заголовок обрабатывается по заявленному правилу
- [ ] Некорректный JSON в теле возвращает 400, а не 500

## Изменение и удаление

- [ ] PATCH /tasks/{id} меняет только переданные поля
- [ ] PATCH с пустым телом не портит объект
- [ ] PATCH чужой задачи возвращает 404
- [ ] PATCH не позволяет изменить служебные поля, например владельца
- [ ] DELETE /tasks/{id} возвращает 204, задача исчезает из списка
- [ ] Повторный DELETE того же id возвращает 404
- [ ] DELETE чужой задачи возвращает 404
- [ ] Неподдерживаемые методы возвращают 405

## Общее по контракту

- [ ] Коды ответов соответствуют смыслу операции
- [ ] Тело ошибки имеет единый формат: код, сообщение, поле
- [ ] Content-Type ответов - application/json
- [ ] Даты в ответах в едином формате
