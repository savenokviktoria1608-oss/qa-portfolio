# Баг-репорты · Таскер API

Оформление - по шаблону из `templates/bug-report.md`. Ниже разобранный пример; остальные
находки по этому стенду веду в том же формате.

---

**ID:** BUG-TASKS-01
**Краткое описание:** Чужая задача доступна по прямому обращению к id

**Окружение:** стенд «Таскер API» (bugrank.gripe), встроенная консоль запросов

**Предусловия:** получен токен пользователя alice, известен id задачи другого пользователя

**Шаги воспроизведения:**
1. POST /auth/login с логином alice и паролем alice123, сохранить токен
2. Выполнить GET /tasks/{id чужой задачи} с заголовком Authorization: Bearer {{token}}

**Фактический результат:** 200 OK, в теле ответа возвращается объект чужой задачи со всеми полями

**Ожидаемый результат:** 404 Not Found, данные чужой задачи не раскрываются

**Критичность:** critical
**Приоритет:** high
**Обоснование:** нарушение разграничения доступа, утечка данных другого пользователя через перебор id

**Воспроизводимость:** 100%

**Вложения:** запрос, заголовки и тело ответа
