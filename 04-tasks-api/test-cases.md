| Поле | Значение |
|---|---|
| **ID** | TC-TASKS-01 |
| **Заголовок** | Чужая задача недоступна по прямому id |
| **Модуль** | Права доступа |
| **Приоритет** | high |
| **Тип** | негативный |
| **Техника** | предугадывание ошибок |

**Предусловия:** получен токен пользователя, известен id задачи другого пользователя

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | POST /auth/login, сохранить токен | 200, токен получен |
| 2 | GET /tasks/{чужой id} с этим токеном | 404, тело ошибки без данных чужой задачи |
| 3 | PATCH /tasks/{чужой id} | 404, объект не изменён |
| 4 | DELETE /tasks/{чужой id} | 404, объект не удалён |
