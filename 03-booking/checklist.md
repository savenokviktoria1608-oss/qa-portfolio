# Чек-лист · Бронирование отеля «Релиз»

Функциональность: выбор дат, число гостей, типы номеров, завтраки, туристический налог,
расчёт стоимости, отмена брони.

## Даты заезда и выезда

- [ ] Дата выезда строго позже даты заезда
- [ ] Выбор выезда раньше заезда отклоняется с сообщением
- [ ] Заезд и выезд в один день отклоняются
- [ ] Число ночей равно разнице дат, а не количеству календарных дней
- [ ] Бронь на одну ночь оформляется корректно
- [ ] Бронь на максимально допустимое число ночей проходит
- [ ] Превышение максимального срока отклоняется с указанием предела
- [ ] Даты в прошлом недоступны
- [ ] Переход через границу месяца считается верно
- [ ] Переход через границу года считается верно

## Гости и номера

- [ ] Число взрослых не может быть нулевым
- [ ] Число детей может быть нулевым
- [ ] Общее число гостей не превышает вместимость номера
- [ ] Превышение вместимости отклоняется с указанием предела
- [ ] Номер, доступный в единственном экземпляре, нельзя забронировать дважды на пересекающиеся даты
- [ ] Описание и вместимость номера соответствуют заявленным

## Расчёт стоимости

- [ ] Стоимость проживания равна цене за ночь × число ночей
- [ ] Завтраки добавляются за каждого гостя за каждую ночь
- [ ] Отключение завтраков убирает их из расчёта
- [ ] Туристический налог начисляется по заявленному правилу
- [ ] Налог пересчитывается при изменении числа гостей и ночей
- [ ] Итог равен сумме всех составляющих
- [ ] В разбивке стоимости нет расхождения с итогом
- [ ] Округление денежных значений не теряет копейки

## Отмена брони

- [ ] Активную бронь можно отменить
- [ ] После отмены статус брони меняется на «отменена»
- [ ] Повторная отмена той же брони невозможна
- [ ] Штраф за отмену рассчитывается по заявленному правилу
- [ ] Отменённая бронь освобождает номер на эти даты
- [ ] Отменённая бронь не участвует в расчётах как активная

## Интерфейс

- [ ] Формат дат единый на всех экранах
- [ ] Сообщения об ошибках привязаны к полю, в котором ошибка
- [ ] Вёрстка не ломается при 1280, 768 и 375 px
