# Тест-кейсы · PayFlow API

| Поле | Значение |
|---|---|
| **ID** | TC-PAY-01 |
| **Заголовок** | Повтор запроса с тем же Idempotency-Key не создаёт второй платёж |
| **Модуль** | Идемпотентность |
| **Приоритет** | high |
| **Тип** | негативный |
| **Техника** | предугадывание ошибок |

**Предусловия:** получен действующий токен, зафиксирован баланс

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | POST /payments с заголовком Idempotency-Key: key-001 | 201, платёж создан, записан его id |
| 2 | Повторить тот же запрос с тем же ключом и тем же телом | Возвращён тот же платёж, новый id не создан |
| 3 | GET /payments и сверить количество | Платёж в списке один |
| 4 | GET /balance | Списание произошло один раз |
| 5 | Повторить запрос с ключом key-002 | Создан новый платёж с новым id |

| **Приоритет** | high |
| **Тип** | негативный |

| № | Действие | Ожидаемый результат |

| 3 | GET /balance | Баланс не изменился после отказа |
| 4 | GET /payments | Отклонённый платёж не числится успешным |
