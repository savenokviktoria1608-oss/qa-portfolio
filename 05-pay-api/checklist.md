# Чек-лист · PayFlow API

REST API платежей: создание платежа, список и получение по id, возвраты, баланс,
идемпотентность, тестовые карты.

## Создание платежа

- [ ] POST /payments с корректным телом возвращает 201 и объект платежа
- [ ] В ответе есть id, сумма, валюта, статус и последние 4 цифры карты
- [ ] Полный номер карты в ответе не возвращается
- [ ] Успешная тестовая карта даёт статус succeeded
- [ ] Карта отказа даёт 402 и код ошибки card_declined
- [ ] Сумма на нижней границе диапазона принимается
- [ ] Сумма на верхней границе диапазона принимается
- [ ] Сумма ниже нижней границы отклоняется с 400
- [ ] Сумма выше верхней границы отклоняется с 400
- [ ] Нулевая и отрицательная сумма отклоняются
- [ ] Дробная сумма обрабатывается по заявленному правилу
- [ ] Валюта принимается в любом регистре
- [ ] Неподдерживаемая валюта отклоняется с 400
- [ ] Номер карты с пробелами принимается наравне с номером без пробелов
- [ ] Номер неверной длины отклоняется с 400
- [ ] Номер, не проходящий проверку Луна, отклоняется
- [ ] Отсутствие обязательного поля даёт 400 с указанием поля
- [ ] Некорректный JSON даёт 400, а не 500

## Идемпотентность

- [ ] Повтор запроса с тем же Idempotency-Key возвращает тот же платёж
- [ ] Повтор с тем же ключом не создаёт второй платёж и не списывает деньги дважды
- [ ] Запрос с новым ключом создаёт новый платёж
- [ ] Тот же ключ с другим телом обрабатывается по заявленному правилу
- [ ] Запрос без заголовка идемпотентности выполняется как обычный

## Список и получение

- [ ] GET /payments возвращает 200 и список платежей
- [ ] Фильтр по статусу возвращает только платежи этого статуса
- [ ] Неизвестный статус в фильтре обрабатывается предсказуемо
- [ ] GET /payments/{id} существующего платежа возвращает 200
- [ ] Неизвестный id возвращает 404 с кодом payment_not_found
- [ ] Структура объекта в списке и по id совпадает

## Возвраты

- [ ] Полный возврат успешного платежа переводит его в refunded
- [ ] Частичный возврат переводит платёж в partially_refunded
- [ ] Сумма возвратов не может превысить сумму платежа
- [ ] Повторный возврат сверх остатка отклоняется
- [ ] Возврат нулевой и отрицательной суммы отклоняется
- [ ] Возврат по отклонённому платежу невозможен
- [ ] Возврат по уже полностью возвращённому платежу невозможен
- [ ] Поле refunded отражает фактическую сумму возвратов

## Баланс и общее по контракту

- [ ] GET /balance возвращает 200 и текущий баланс
- [ ] Баланс меняется согласованно с платежами и возвратами
- [ ] Запросы без авторизации возвращают 401
- [ ] Неподдерживаемые методы возвращают 405
- [ ] Формат тела ошибки единый: код, сообщение, поле
- [ ] Даты в ответах в формате ISO 8601 и в UTC
