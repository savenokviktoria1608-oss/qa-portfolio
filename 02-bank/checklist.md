# Чек-лист · Мини-банк

Функциональность: счета и балансы, переводы между своими счетами и внешним получателям,
комиссия, дневной лимит, обмен валюты, история операций.

## Счета и балансы

- [ ] Отображаются все счета: карточный, накопительный, валютный
- [ ] Баланс каждого счёта показан в своей валюте с корректным символом
- [ ] Формат денежных значений единый на всех экранах
- [ ] Баланс обновляется сразу после операции

## Переводы

- [ ] Перевод между своими счетами уменьшает баланс отправителя и увеличивает баланс получателя
- [ ] Сумма перевода и сумма зачисления сходятся с учётом комиссии
- [ ] Перевод на тот же самый счёт запрещён с понятным сообщением
- [ ] Перевод суммы больше баланса отклоняется
- [ ] Перевод нулевой и отрицательной суммы отклоняется
- [ ] Граничные значения суммы: 0, 0.01, баланс минус копейка, ровно баланс, баланс плюс копейка
- [ ] Нечисловые значения в поле суммы отклоняются
- [ ] Сумма с тремя и более знаками после запятой либо отклоняется, либо округляется по правилу

## Комиссия

- [ ] Комиссия рассчитывается по заявленному проценту
- [ ] Минимальная комиссия применяется, когда процент даёт меньшую сумму
- [ ] Комиссия показана до подтверждения перевода
- [ ] Списанная сумма равна сумме перевода плюс комиссия
- [ ] Комиссия округляется в одну сторону и не теряет копейки

## Дневной лимит

- [ ] Перевод в пределах лимита проходит
- [ ] Перевод ровно на остаток лимита проходит
- [ ] Перевод, превышающий остаток лимита, отклоняется
- [ ] В сообщении об отказе указан фактический остаток лимита
- [ ] Остаток лимита уменьшается на сумму проведённых переводов
- [ ] В лимит засчитывается сумма перевода, комиссия учтена по заявленному правилу

## Обмен валюты

- [ ] Обмен по текущему курсу зачисляет корректную сумму
- [ ] Обратный обмен той же суммы не создаёт прибыль из воздуха
- [ ] Округление при конвертации не теряет и не добавляет копейки
- [ ] Обмен суммы больше баланса отклоняется

## История операций

- [ ] Операция появляется в истории сразу после проведения
- [ ] В записи указаны тип, сумма, счета, дата и комиссия
- [ ] Фильтр «переводы» показывает только переводы
- [ ] Фильтр «обмен» показывает только обмены
- [ ] Фильтр «поступления» показывает только зачисления
- [ ] Сброс фильтра возвращает полную историю
- [ ] Суммы в истории совпадают с фактическими изменениями баланса
