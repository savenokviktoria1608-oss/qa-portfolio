# Тест-кейсы · Мини-банк

| Поле | Значение |
|---|---|
| **ID** | TC-BANK-01 |
| **Заголовок** | Минимальная комиссия применяется при малой сумме перевода |
| **Модуль** | Переводы, комиссия |
| **Приоритет** | high |
| **Тип** | граничный |
| **Техника** | граничные значения, таблица решений |

**Предусловия:** на карточном счёте достаточно средств, известны процент комиссии и её минимум

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Перевести сумму, при которой процент даёт комиссию меньше минимума | Списана минимальная комиссия |
| 2 | Перевести сумму, при которой процент даёт комиссию ровно минимум | Списана минимальная комиссия, двойного применения нет |
| 3 | Перевести сумму, при которой процент даёт комиссию больше минимума | Списана комиссия по проценту |
| 4 | Сверить баланс после каждой операции | Списано: сумма перевода плюс комиссия |
