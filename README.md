## Что внутри

```
templates/          шаблоны, по которым оформляю документацию
01-shop-lapki/      интернет-магазин: каталог, поиск, корзина, промокоды, заказ
02-bank/            мини-банк: счета, переводы, комиссии, лимиты, обмен валюты
03-booking/         бронирование отеля: даты, гости, номера, завтраки, налог, отмена
04-tasks-api/       REST API задач: авторизация, CRUD, фильтры, пагинация, права доступа
05-pay-api/         REST API платежей: платежи, возвраты, идемпотентность, тестовые карты
```

В каждой папке:

- `checklist.md` - чек-лист покрытия функциональности
- `test-cases.md` - тест-кейсы с предусловиями, шагами и ожидаемым результатом
- `bug-reports.md` - баг-репорты по найденным дефектам
- `postman/` - коллекция запросов (только у API-стендов)
