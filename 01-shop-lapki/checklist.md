# Чек-лист · Интернет-магазин «Лапки»

Функциональность: каталог товаров, поиск, сортировка, корзина, промокод, оформление заказа.

## Каталог

- [ ] Карточки товаров отображаются: название, цена, категория
- [ ] Цена в карточке совпадает с ценой в корзине
- [ ] Фильтр по категории оставляет только товары этой категории
- [ ] Сброс фильтра возвращает полный каталог
- [ ] Сортировка по возрастанию цены: порядок числовой, а не строковый (проверить товары с ценой из одной и двух цифр)
- [ ] Сортировка по убыванию цены работает симметрично
- [ ] Сортировка сохраняется при переключении категории
- [ ] Пустая выдача сопровождается понятным сообщением, а не пустым экраном

## Поиск

- [ ] Поиск по полному названию товара находит товар
- [ ] Поиск по части названия находит товар
- [ ] Поиск нечувствителен к регистру: «корм», «Корм», «КОРМ» дают одинаковый результат
- [ ] Пробелы в начале и конце запроса не влияют на результат
- [ ] Поиск по несуществующему товару даёт сообщение о пустом результате
- [ ] Поиск в сочетании с фильтром по категории не теряет условия

## Корзина

- [ ] Товар добавляется в корзину, счётчик увеличивается
- [ ] Повторное добавление увеличивает количество, а не создаёт вторую строку
- [ ] Количество меняется кнопками и вручную
- [ ] Количество нельзя сделать нулевым или отрицательным
- [ ] Граничные количества: 1, 9, 10, 11, 99 - сумма строки равна цене × количество
- [ ] Удаление товара пересчитывает итог
- [ ] Очистка корзины обнуляет итог и счётчик
- [ ] Сумма корзины равна сумме строк
- [ ] Корзина сохраняется при переходе между разделами

## Промокод

- [ ] Действующий промокод применяется и уменьшает итог на заявленный процент
- [ ] Повторный ввод того же промокода не даёт вторую скидку
- [ ] Несуществующий промокод отклоняется с сообщением об ошибке
- [ ] Промокод в другом регистре обрабатывается так же, как в исходном
- [ ] Пустое поле промокода не ломает расчёт
- [ ] Скидка пересчитывается при изменении состава корзины
- [ ] Отображаемая скидка совпадает с разницей между суммой и итогом

## Оформление заказа

- [ ] Оформление недоступно при пустой корзине
- [ ] Обязательные поля формы валидируются
- [ ] Некорректные данные (телефон, email) отклоняются с пояснением
- [ ] Итоговая сумма в заказе совпадает с суммой в корзине
- [ ] После оформления корзина очищается

## Интерфейс

- [ ] Вёрстка не ломается при 1280, 768 и 375 px
- [ ] Денежные значения отображаются в одном формате
- [ ] Длинные названия не выходят за границы карточек
