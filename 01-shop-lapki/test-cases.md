| Поле | Значение |
|---|---|
| **ID** | TC-SHOP-01 |
| **Заголовок** | Сумма строки корзины при количестве на границе десятка |
| **Модуль** | Корзина |
| **Приоритет** | high |
| **Тип** | граничный |
| **Техника** | граничные значения |

**Предусловия:** корзина пуста, в каталоге есть товар с известной ценой

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Добавить товар в корзину | Товар в корзине, количество 1, сумма строки равна цене |
| 2 | Установить количество 9 | Сумма строки равна цене × 9 |
| 3 | Установить количество 10 | Сумма строки равна цене × 10 |
| 4 | Установить количество 11 | Сумма строки равна цене × 11 |
| 5 | Сверить итог корзины | Итог равен сумме всех строк |
